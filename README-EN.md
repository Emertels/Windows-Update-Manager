Autonomous PowerShell manager to audit, search, download, and selectively install Windows Update cumulative patches and security fixes.

## 🚀 Key Features
- **Targeted KB Search:** Queries Microsoft update servers for pending cumulative and driver updates.
- **Selective Installation:** Choose precisely which updates to download and install.
- **Component Cleanup:** Includes maintenance routines for WinSxS store cleanup and update cache resets.
- **Multilingual Support:** 10 built-in languages automatically resolved from system locale.

## 📦 Usage
1. Download from [Releases](https://github.com/Emertels/Windows-Update-Manager/releases/latest).
2. Run `Windows-Update-Manager.ps1` in PowerShell as Administrator.
3. Follow the menu prompts to check for updates or run system maintenance.
